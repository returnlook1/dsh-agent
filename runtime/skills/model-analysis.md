# 模拟结果分析

## 分析前先对齐

1. **同源对比**：模拟与观测必须同区域、同时段、同口径（日均对日均，UTC 对 UTC）。
2. **匹配方式**：点对点（最近邻）还是面平均？写出匹配半径（例如 3 km）。
3. **样本量**：给出参与统计的样本数 N；N < 30 时不要下强结论。

## 常用指标

| 指标 | 公式/含义 | 判读 |
| --- | --- | --- |
| RMSE | `sqrt(mean((sim - obs)^2))` | 与观测标准差比较，接近才说明有技巧 |
| Bias | `mean(sim - obs)` | 看系统偏差方向 |
| R | 皮尔逊相关系数 | 只看相位一致性，不看振幅 |
| 技能评分 | `1 - MSE_model / MSE_persistence` | > 0 才算优于持续性预报 |

## 可信度表述

- 明确区分"模型输出"与"实测"；不要在结论里混用。
- 近岸、极浅水、强径流期三项误差通常偏大，需要在结论中提示。
- 数据未同化实测时，说明"未同化"而不是"高精度"。

## 输出格式

```
结论：2026-10 长江口流速模拟 RMSE 0.19 m/s（N=168），较 7 月下降 12%，但仍高于观测标准差 0.15 m/s。
判读：相位一致性较好（R=0.86），系统偏差 +0.03 m/s（略偏快）。
限制：仅与 2 个浮标对比，未覆盖南槽；模型未同化实测流量。
```

## 不要做的事

- 不要用 R² 单独证明"模拟准确"。
- 不要在没有 N 与时段说明的情况下给"误差 10%"这类数字。
