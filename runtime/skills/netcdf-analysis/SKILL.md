# NetCDF 数据分析

## 先确认四件事

在给出任何数值结论之前，必须先明确（缺什么就问用户，不要猜）：

1. **数据集**：用 `search_dataset` 找到目标数据集，再用 `get_dataset_meta` 读取变量清单、
   时间范围、空间网格与格式。
2. **变量**：海洋模式常见 `u`/`v`（流速分量，m/s）、`w`（垂向速度）、`zeta`（水位，m）、
   `temp`（位温，℃）、`salt`（盐度，PSU）。不要假设变量名，以元信息为准。
3. **时间与口径**：明确时区（模式输出通常是 UTC）、时间步长、是否需要日均/月均。
   统计前先声明时间窗口，例如"2026-10-18 ~ 2026-10-24，日均"。
4. **空间范围**：Curvilinear 网格不能直接用经纬度切片；需要先说明网格类型，
   再按 `eta_rho`/`xi_rho` 索引范围或提供区域掩膜。

## 计算约定

- 流速大小：`sqrt(u^2 + v^2)`；主流向用 `atan2(v, u)` 换算成角度（0°=正东，逆时针为正）。
- 缺测值：注意 `_FillValue` / `missing_value`，统计前剔除，不要当成 0。
- 单位换算：cm/s → m/s 需 ÷100；非 SI 单位必须在结论里标注。
- 数据量超过 400 GB 的数据集不要建议全量下载，先给出切片方案。

## 输出格式

先给结论，再给依据：

```
结论：长江口 2026-10-20 平均流速 0.82 m/s，主流向 118°（东南偏东）。
依据：ocean-flow-2026（u/v/w，1h，900x600 curvilinear），2026-10-20 00:00–23:00 UTC 全网格平均。
注意：模式输出未同化实测，近岸 3 km 内误差可能偏大。
```

## 不要做的事

- 不要编造变量名、文件路径或统计数据；没有工具结果就明说"需要先查询数据集"。
- 不要把不同数据集的时间序列直接相减比较（网格与同化方案不同）。
