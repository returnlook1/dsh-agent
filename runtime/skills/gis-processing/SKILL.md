# GIS 处理

## 坐标系

- 明确 EPSG 代码再动手。中国近海常用 `EPSG:4326`（经纬度）与 `EPSG:3857`（Web 墨卡托）；
  工程坐标需要用户给出地方带号（如 CGCS2000 3 度带）。
- 面积、长度量测必须在**等积/等距**坐标系下进行；在 `EPSG:4326` 下直接算面积是错的。
- 转换前后都记录：源 CRS、目标 CRS、转换参数来源。

## 栅格与矢量

| 任务 | 通用做法 |
| --- | --- |
| 栅格切片 | 先按 bbox 裁剪，再重采样；不要先重采样再裁剪 |
| 栅格转矢量 | 先平滑/众数滤波再取等值线，避免锯齿 |
| 矢量转栅格 | 明确像元对齐方式（中心/角点）与 `all_touched` 语义 |
| 叠加分析 | 先统一 CRS，再统一分辨率，最后叠加 |

## 地图交互

- 定位到某点时给 `zoom`：区域级 8–10，站点级 12–14，工程级 15+。
- 汇报坐标时同时给经纬度与所在行政区（便于人工核对）。
- 图层顺序：底图 → 面（面填充透明度 ≥ 40%）→ 线 → 点 → 标注。

## 输出格式

```
结论：已在长江口（121.9°E, 31.4°N）定位，建议 zoom 11。
图层：ocean-flow-2026 日均流速（栅格，色带 YlOrRd）→ 6 个监测站（点）。
注意：原始数据为 Curvilinear 网格，已双线性重采样到 EPSG:4326。
```

## 不要做的事

- 不要在未确认 CRS 的情况下回答"距离约 xx 公里"。
- 不要把 Web 墨卡托下的像素距离当成实际距离。
